Welcome to the home of **Frags** and its ecosystem.

## What is Frags?

Frags is a Golang library and CLI tool designed to build and run AI-driven automation blueprints for complex data retrieval, transformation, extraction, and aggregation. 

Engineered for precision and focus, Frags is a specialized orchestration system built for developers and technical teams—not a code-free quick fix.

### Key Capabilities

* **Engineered for Engineers:** Available both as a standalone **CLI** and as a **Golang library** to embed directly into your infrastructure.
* **Deterministic Structured Output:** Dedicated almost exclusively to generating predictable, machine-consumable data structures ready for downstream consumption.
* **Anti-Context-Bloating:** A multi-session framework that isolates context per task, eliminating hallucination risks and maintaining strict LLM focus.
* **Output Segmentation:** Bypasses LLM output token limits by segmenting complex generation into controlled sub-tasks.
* **Advanced Tool & Hybrid Workflows:** Native integration for internal code tools and external Model Context Protocol (MCP) servers, backed by custom pre/post-processing scripts and transformers.
* **Multi-LLM Support:** Seamlessly switch between different provider backends to suit specific pipeline steps.

### Common Use Cases

* **Deep Research & Paper Generation:** Orchestrate structured multi-section analysis combining local document ingestion with real-time web search.
* **Structured Data Extraction & Transformation:** Extract verified fields from unstructured documents or query data sources to build structured data models.
* **Automated Reporting:** Aggregate telemetry, database metrics, and external sources into comprehensive system-wide status reports.
* **Content & Note Augmentation:** Expand concise notes or drafts into fully structured, rich documentation.
